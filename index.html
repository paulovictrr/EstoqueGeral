DADOS PESSOAIS

Política de Privacidade

Dados tratados: o sistema pode armazenar nomes e classificações de produtos, quantidades, preços, validade, movimentações e dados de fornecedores, incluindo nome, contato, endereço e CNPJ.

Armazenamento: os registros são guardados localmente no navegador, neste aparelho. O aplicativo não possui conta de usuário nem banco de dados próprio e não envia esses registros a um servidor do sistema. Limpar os dados do navegador pode removê-los.

Arquivos gerados: backups CSV e relatórios PDF/Excel são montados no navegador e baixados para o aparelho. O usuário decide se vai guardá-los ou compartilhá-los.

Serviços externos: a página é hospedada pelo GitHub Pages. A exportação Excel carrega a biblioteca xlsx-js-style pelo jsDelivr; esses serviços recebem solicitações técnicas do navegador para entregar a página e a biblioteca. O conteúdo dos cadastros não é enviado à biblioteca para gerar o arquivo.

Responsabilidade e cuidados: a pessoa ou organização que decide cadastrar dados de fornecedores deve limitar o acesso e inserir apenas informações necessárias. Para registros neste aparelho, revise, corrija ou exclua os dados no sistema; para apagá-los por completo, também é possível limpar o armazenamento local do navegador.
