DADOS PESSOAIS

Política de Privacidade

Dados tratados: o sistema pode armazenar nome e e-mail da conta, nome da empresa, nomes e classificações de produtos, quantidades, preços, validade, movimentações e dados de fornecedores e clientes, incluindo contato, endereço e CNPJ. A senha da empresa é armazenada como hash criptográfico, não em texto aberto.

Armazenamento: os registros compartilhados da empresa são guardados no projeto Supabase conectado pelo responsável. O e-mail e o nome do usuário são usados pelo serviço de autenticação do Supabase. Uma cópia de trabalho também fica no armazenamento local do navegador enquanto a conta está conectada; sair da conta limpa essa cópia deste aparelho.

Arquivos gerados: As exportações CSV de tabelas, o backup completo da empresa em JSON e relatórios PDF/Excel são gerados no navegador e baixados para o aparelho. O backup completo JSON contém dados comerciais e pode incluir dados pessoais; proteja o arquivo. O usuário decide se vai guardá-los ou compartilhá-los.

Serviços externos: a página é hospedada pelo GitHub Pages. A exportação Excel carrega a biblioteca xlsx-js-style pelo jsDelivr; esses serviços recebem solicitações técnicas do navegador para entregar a página e a biblioteca. Os registros são enviados ao projeto Supabase configurado para permitir o acesso entre aparelhos; a biblioteca Excel é usada apenas para montar os arquivos no navegador.

Responsabilidade e cuidados: a pessoa ou organização que decide cadastrar dados de fornecedores deve limitar o acesso e inserir apenas informações necessárias. Para registros neste aparelho, revise, corrija ou exclua os dados no sistema; para apagá-los por completo, também é possível limpar o armazenamento local do navegador.
